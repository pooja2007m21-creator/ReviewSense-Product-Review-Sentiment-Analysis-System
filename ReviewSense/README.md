# ReviewSense – Product Review Sentiment Analysis System

## Run
```bash
python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000. On first run the model trains automatically and is saved as `ml/model.joblib`; `database.db` is created automatically.

## How the ML works
`ml/preprocess.py` lowercases, tokenizes, removes stop words (keeping negators) and marks negation ("not happy" becomes `not_happy`). `ml/train.py` builds a TF-IDF + Logistic Regression pipeline, trains on 80% of the data and reports accuracy on the unseen 20% (`ml/metrics.json`, shown on the Dashboard). `ml/predict.py` returns the sentiment, probabilities, a score (P(positive) minus P(negative)) and the words that contributed most. Clauses are classified separately, and a keyword list finds product topics (battery, price, delivery...) whose sentiment comes from the model. Bulk mode analyzes up to 100 reviews (one per line).

## Important: training data
`ml/data/seed_reviews.csv` is a small **synthetic demo dataset** (generated by `ml/make_seed_data.py`) so the app runs out of the box; its accuracy is not a real-world measure. For real use, download a labeled review dataset (e.g. Amazon Product Reviews or Flipkart Reviews on Kaggle), save it as `ml/data/reviews.csv` with columns `text,label` (`positive`/`negative`/`neutral`) or `text,rating` (1-2 negative, 3 neutral, 4-5 positive), then run:
```bash
python -m ml.train
```
and restart `python app.py`.

## API
`GET /api/health`, `POST /api/analyze`, `POST /api/analyze-batch`, `GET|DELETE /api/history`, `GET|DELETE /api/history/<id>`, `GET /api/analytics`.
